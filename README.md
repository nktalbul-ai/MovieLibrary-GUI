## Описание программы

Библиотека фильмов — это GUI-приложение для управления личной коллекцией фильмов.
снять фильмы, отфильтровать их по жанру и году,
сохранить и загрузить данные в формате JSON, а также просмотреть список с удобной навигацией.

### Возможности

-  Добавить фильм: Вводите название и данные — сохраните фильм.
-  Фильтрация: можно найти фильмы только одного жанра (например, «Комедия») или только за определенный год (например, «2023»).
-  Сохранение: Список фильмов не пропадает после закрытия программы. Он сохраняет в предварительном файле Movies.json.
-  Проверка ошибок: Программа не даст сохранить фильм без названия или если рейтинг больше 10.


### Проверка корректности ввода:
- Год выпуска: должен быть целым числом с 1900 по 2026 год.
- Рейтинг: должно быть числом от 0 до 10 (можно использовать дробные числа)

### Требования:
- Python 3.6 или выше
- Стандартная библиотека Tkinter
